# AI Advent Challenge

Android приложение для взаимодействия с ChatGPT через OpenAI API.

## Описание

Приложение позволяет отправлять текстовые запросы к ChatGPT и получать ответы в реальном времени. Реализовано с использованием Jetpack Compose для современного UI и Retrofit для работы с API.

### Функционал

- ✅ Отправка текстовых запросов к ChatGPT
- ✅ Отображение ответов от AI в удобном интерфейсе
- ✅ Безопасное хранение API ключа (не коммитится в репозиторий)
- ✅ Логирование всех запросов и ответов в Logcat
- ✅ Таймаут запросов 60 секунд для длинных ответов
- ✅ Обработка ошибок с понятными сообщениями
- ✅ Установка максимального количества токенов на ответ модели
- ✅ Остановка генерации ответа моделью при stop sequence "Закончил ответ"
- ✅ Игнорирование ограничений ответа модели
- ✅ **Обсуждение (Discussion):** решение одной задачи четырьмя способами (прямой ответ, пошагово, свой промпт, эксперты) с параллельным запуском и сравнением ответов через API
- ✅ **Главный экран:** стартовая точка с картинкой (AI/робот), названием приложения и раскрывающимися блоками по темам: «Промптинг» (Чат, Обсуждение, Температура, Версии моделей) и отдельный блок **«Агент»** (кнопка «Начать диалог»); на экранах — кнопка «Назад» на главный
- ✅ **Агент:** диалог с AI в виде чата — прокручиваемая история сообщений (пузырьки «Вы» / «Агент»), поле ввода и кнопка «Отправить» внизу; при открытой клавиатуре кнопка остаётся доступной; **история диалога сохраняется между перезапусками приложения** (Room); кнопка «Очистить историю» сбрасывает чат (диалог подтверждения с опцией «Также очистить память задачи»). **Профиль пользователя:** в настройках — выбор «Без профиля» или один из профилей (имя + предпочтения: стиль, формат, ограничения); добавление, редактирование и удаление профилей; активный профиль учитывается агентом в ответах (подставляется в промпт и system message). **Стратегии контекста:** скользящее окно, факты, ветки, сжатие — переключатель и настройки (иконка шестерёнки); при ветках — вкладки и «Создать ветку». **Память:** три слоя — диалог (очищается с историей), память задачи (отдельный список задач, одну можно «подключить» к диалогу), долговременная (профиль/знания, очищается кнопкой «Очистить» в настройках); в настройках — редактирование долговременной памяти и списка задач, кнопки «Сохранить» и «Очистить» для долговременной, подключение/отключение задачи к диалогу; **подключённая задача сохраняется по ветке** — при повторном входе в чат или при переключении ветки она автоматически подставляется. **Локальный индекс (RAG):** в настройках агента можно включить **«Использовать RAG»** — тогда перед ответом ChatGPT приложение подмешивает в запрос короткие выдержки из документации и кода этого репозитория (то, что попало в локальную базу при сборке). Так удобнее спрашивать про устройство проекта, стратегии контекста, Gradle и т.п. Нужны **запущенный Ollama** на вашем компьютере (или в сети), модель эмбеддингов **`nomic-embed-text`** и параметр **`OLLAMA_HOST`** в `secret.properties` (на эмуляторе часто `http://10.0.2.2:11434`, на физическом устройстве — адрес машины с Ollama в Wi‑Fi). Если RAG включён, а хост пустой или Ollama не отвечает, показывается сообщение об ошибке и запрос в OpenAI не уходит, пока вы не исправите настройки. **Инварианты:** в настройках агента блок «Инварианты» — правила, которые агент не должен нарушать (произвольный текст, сохраняется в настройках); при запросе, противоречащем инварианту, агент отказывает и объясняет причину. **Настройки** разбиты на **семь** сворачиваемых блоков (Профиль пользователя, Долговременная память, Память задачи, Стратегия контекста, Локальный индекс (RAG), Инварианты, Отладка). **Команды в поле ввода** (не уходят в модель): `/add_long_term текст`, `/add_task_memory текст`, `/help`. **Длинный тап по сообщению** — извлечь факты и сохранить в долговременную память или в выбранную задачу. В debug-сборке кнопка «Превысить контекст» (слева от «Отправить») для проверки обработки ошибки при превышении лимита контекста API
- ✅ **Температура:** один запрос с разными значениями temperature (0–2): ползунок с шагом 0.1, пресеты «Точность (0)», «Баланс (0.7)», «Креативность (1.2)», «Запустить все три»; список ответов с возможностью сворачивания карточек; сравнение при ≥2 ответах по точности, креативности и разнообразию с рекомендациями по настройкам
- ✅ **Версии моделей:** один запрос выполняется на трёх моделях (GPT-4o mini, GPT-4.1, GPT-5 nano); замер времени ответа, отображение токенов и ориентировочной стоимости; примеры запросов для оценки ограничений моделей; кнопка «Сравнить» — краткий вывод о качестве, скорости и ресурсоёмкости; ссылки на документацию и тарифы OpenAI

## Требования

- Android Studio Hedgehog или новее
- JDK 11 или выше
- Android SDK (minSdk 26, targetSdk 36)
- API ключ OpenAI (получить можно на [platform.openai.com/api-keys](https://platform.openai.com/api-keys))

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd AIAdventChallenge
```

### 2. Настройка API ключа

1. Скопируйте файл `secret.properties.example` в `secret.properties`:
   ```bash
   cp secret.properties.example secret.properties
   ```

2. Откройте `secret.properties` и замените `ваш ключ` на ваш реальный API ключ OpenAI:
   ```
   OPENAI_API_KEY=sk-your-actual-api-key-here
   ```

   ⚠️ **Важно:** Файл `secret.properties` добавлен в `.gitignore` и не будет закоммичен в репозиторий. Никогда не публикуйте свой API ключ!

3. **Опционально — RAG у агента:** если планируете пользоваться локальным индексом документации в чате с агентом, добавьте в `secret.properties` строку **`OLLAMA_HOST=...`** с базовым URL Ollama (без завершающего `/`), например `http://10.0.2.2:11434` для эмулятора. На машине с Ollama один раз выполните `ollama pull nomic-embed-text`. Пример и комментарии — в `secret.properties.example`.

### 3. Сборка проекта

**Локальный индекс и Ollama при сборке.** В APK попадает заранее собранная SQLite-база фрагментов документации репозитория. Задача индексации в Gradle обращается к **Ollama** (модель **`nomic-embed-text`**). Перед первой полной сборкой убедитесь, что Ollama запущен и модель подтянута; иначе шаг `:doc-index:buildDocIndex` может завершиться ошибкой. Как установить Ollama, проверить API и собрать индекс вручную — в [doc-index/README.md](doc-index/README.md).

#### Через Android Studio:

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Нажмите `Build > Make Project` или `Ctrl+F9` (Windows/Linux) / `Cmd+F9` (Mac)
4. Для запуска на эмуляторе или устройстве: `Run > Run 'app'` или `Shift+F10` (Windows/Linux) / `Ctrl+R` (Mac)

#### Через командную строку:

```bash
# Сборка debug APK
./gradlew assembleDebug

# Установка на подключенное устройство
./gradlew installDebug

# Запуск приложения
adb shell am start -n com.example.aiadventchallenge/.MainActivity
```

## Использование

При запуске открывается **главный экран**: картинка на тему AI и робота, название «Ai Advent Challenge With Love» и раскрывающиеся блоки по темам. Блок **«Промптинг»** — Чат, Обсуждение, Температура, Версии моделей. Отдельный блок **«Агент»** — кнопка «Начать диалог» для перехода в чат с агентом. На всех экранах кнопка **«Назад»** возвращает на главный экран.

### Чат

1. На главном экране откройте блок «Промптинг» и нажмите **«Чат»**.
2. В поле "Ваш запрос" введите вопрос или сообщение для ChatGPT
3. Нажмите кнопку "Отправить"
4. Ответ от ChatGPT появится в поле "Ответ"

### Обсуждение (Discussion)

1. На главном экране в блоке «Промптинг» нажмите **«Обсуждение»**
2. Введите задачу (логическую, алгоритмическую или аналитическую)
3. Запустите один способ (Прямой, Пошагово, Свой промпт, Эксперты) или кнопку **«Запустить все»** для параллельного выполнения всех четырёх
4. Ответы появятся в соответствующих блоках; для «Свой промпт» отображается сгенерированный моделью промпт
5. При наличии минимум двух ответов нажмите **«Сравнить»** — модель даст краткое сравнение и укажет наиболее точный способ

### Температура

1. На главном экране в блоке «Промптинг» нажмите **«Температура»**
2. Введите запрос (один и тот же запрос будет отправлен с разными значениями temperature)
3. Выберите значение ползунком (0–2, шаг 0.1) и нажмите **«Запустить»** или используйте пресеты («Точность (0)», «Баланс (0.7)», «Креативность (1.2)») или **«Запустить все три»**
4. Ответы появятся в карточках; карточки можно сворачивать и разворачивать по нажатию на заголовок
5. При наличии минимум двух ответов нажмите **«Сравнить»** — модель сравнит ответы по точности, креативности и разнообразию и подскажет, для каких задач лучше подходит каждая настройка температуры

### Версии моделей

1. На главном экране в блоке «Промптинг» нажмите **«Версии моделей»**
2. Введите запрос или выберите один из примеров (Рассуждение по шагам, Факты и даты, Креатив и др.) — текст подставится в поле
3. Нажмите **«Запустить все три модели»** — один и тот же запрос отправится в GPT-4o mini, GPT-4.1 и GPT-5 nano
4. В карточках появятся ответы с временем ответа (мс), количеством токенов и ориентировочной стоимостью; карточки можно сворачивать и разворачивать
5. Нажмите **«Сравнить»** — модель даст короткий вывод о качестве ответов, скорости и ресурсоёмкости и подскажет, когда какую модель лучше использовать
6. Внизу экрана — ссылки на страницу моделей OpenAI и тарифы

### Агент

1. На главном экране раскройте блок **«Агент»** и нажмите **«Начать диалог»**
2. Введите сообщение в поле внизу экрана и нажмите **«Отправить»**
3. Ответ агента появится в чате (пузырёк «Агент»); история диалога прокручивается вверх
4. Можно продолжать обмен сообщениями — агент учитывает контекст беседы (стратегия отображается в шапке)
5. При открытой клавиатуре кнопка «Отправить» остаётся видимой и нажимаемой
6. **История диалога сохраняется:** после перезапуска приложения чат восстанавливается полностью; при использовании веток — переключайтесь между вкладками; **подключённая к диалогу задача** (если вы подключали её в настройках) тоже восстанавливается при повторном входе или при возврате на эту ветку
7. **Настройки** (иконка шестерёнки) — **семь** сворачиваемых блоков (по нажатию на заголовок блок разворачивается или сворачивается): **профиль пользователя** — «Без профиля» или выбор одного из профилей (имя + предпочтения); кнопки «Добавить профиль», «Изменить», «Удалить». **Долговременная память** — поле ввода, «Сохранить» и «Очистить». **Память задачи** — список задач, «Загрузить в диалог» / «Отключить», добавление и удаление, «Очистить память задачи» (подключённая задача сохраняется для текущей ветки). **Стратегия контекста** — скользящее окно, факты, ветки, сжатие и число последних сообщений (5/10/20). **Локальный индекс (RAG)** — переключатель «Использовать RAG»: при включении перед каждым сообщением к агенту подбираются фрагменты встроенной документации (нужны корректный `OLLAMA_HOST` и доступный Ollama с `nomic-embed-text`). **Инварианты** — правила, которые агент не должен нарушать (многострочное поле, «Сохранить»); при запросе, противоречащем инварианту, агент отказывает и объясняет. **Отладка** — чекбокс «Показать кнопку „Превысить контекст“». **Жизненный цикл задачи:** командой `/start_task` запускается цикл этапов (Планирование → Выполнение → Проверка → Готово); этапы не зависят от подключённой задачи (памяти задачи). Переход вперёд по `/confirm`, назад по `/reject`, остановка — `/stop_task`. Модель знает текущий этап и не может перескочить на следующий без явного подтверждения `/confirm` от пользователя. При выходе с экрана задача на паузе. Кнопка **«Команды»** открывает список команд (/start_task, /stop_task, /confirm, /reject, /reset_planning, /help, /add_long_term, /add_task_memory); выполнение как при вводе вручную
8. **Команды в поле ввода** (по «Отправить» выполняются действия с памятью, запрос в модель не уходит): `/add_long_term текст` — извлечь факты и добавить в долговременную память; `/add_task_memory текст` — в подключённую задачу (если ни одна не подключена — появится подсказка); `/help` — подсказка по командам
9. **Длинный тап по сообщению** — «Извлечь факты и сохранить» → «В долговременную память» или «В задачу: [имя]»; модель извлекает факты из сообщения, результат сохраняется в выбранный слой
10. Кнопка **«Очистить историю»** открывает диалог подтверждения; при необходимости отметьте «Также очистить память задачи»
11. В debug-сборке слева от «Отправить» отображается кнопка **«Превысить контекст»** — нажатие отправляет искусственно раздутый запрос, чтобы проверить отображение ошибки API при превышении лимита контекста

### Просмотр логов

Все HTTP запросы и ответы к OpenAI логируются в Logcat с тегом `OpenAI`. Для просмотра:

1. В Android Studio откройте вкладку **Logcat**
2. В фильтре введите `OpenAI` или выберите тег `OpenAI`
3. Вы увидите полные запросы и ответы API

Для отладки **локального индекса (RAG)** и эмбеддингов Ollama смотрите теги **`RagContextBuilder`** и **`OllamaRag`** (размер вектора, число найденных фрагментов, ошибки сети к Ollama).

## Технологии

- **Kotlin** - основной язык разработки
- **Jetpack Compose** - современный UI фреймворк
- **Retrofit** - HTTP клиент для работы с API
- **OkHttp** - HTTP клиент с логированием
- **Coroutines** - асинхронное программирование
- **ViewModel** - управление UI состоянием
- **Material 3** - дизайн система
- **Room** - локальная БД для диалога агента (сообщения по веткам, summaries, facts, ветки с подключённой задачей и состоянием этапов, долговременная память, память задач, профили пользователя)
- **Локальный индекс (RAG)** — встроенная SQLite-база `doc_index.sqlite` (собирается модулем `doc-index` при сборке APK с помощью Ollama); на устройстве для поиска по запросу пользователя используются эмбеддинги через тот же Ollama по адресу `OLLAMA_HOST`

## Модели AI

Модель по умолчанию для чата и других экранов задаётся в `OpenAiDto.kt` (например, `gpt-4.1`). На экране **«Версии моделей»** один запрос выполняется на трёх моделях: **GPT-4o mini** (слабая), **GPT-4.1** (средняя), **GPT-5 nano** (сильная) — с замером времени, токенов и стоимости; список моделей и цены в `ChatRepository.kt` (`MODELS_FOR_COMPARISON`, `PRICING_PER_1M`).

## Устранение неполадок

### Ошибка "OPENAI_API_KEY не задан"

Убедитесь, что:
- Файл `secret.properties` существует в корне проекта
- В файле указан корректный ключ (не "ваш ключ")
- После изменения `secret.properties` выполните `Build > Clean Project` и `Build > Rebuild Project`

### Ошибки сборки

1. Выполните `File > Invalidate Caches / Restart` в Android Studio
2. Удалите папки `.gradle` и `build` в корне проекта
3. Выполните `./gradlew clean` в терминале
4. Пересоберите проект

### Проблемы с сетью

- Проверьте подключение к интернету
- Убедитесь, что устройство/эмулятор имеет доступ в сеть
- Проверьте логи в Logcat для деталей ошибки

### RAG и Ollama

- **Сборка падает на индексе** — запустите Ollama, выполните `ollama pull nomic-embed-text`, повторите сборку; см. [doc-index/README.md](doc-index/README.md).
- **Включён RAG, но запрос не уходит** — проверьте `OLLAMA_HOST` (для эмулятора к Ollama на ПК обычно `http://10.0.2.2:11434`), доступность порта с устройства и логи `RagContextBuilder` / `OllamaRag`.
